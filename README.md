# Fosho homepage

Public static website for Fosho, a hospital-specialist online marketing agency.

This repository contains only website runtime files. The approved V3 is now the main homepage. A comparison copy remains at `v3/` with indexing disabled. Project plans, research notes, source PDFs, and design reviews are excluded.

GitHub Pages publishes the `main` branch from the repository root.

- Homepage: https://fosho.co.kr/
- Comparison: https://fosho.co.kr/v3/

Canonical URLs, social metadata, structured data, and sitemap URLs are generated together from the configured domain. `robots.txt` is served at the hostname root.
