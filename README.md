# Fosho homepage

Public static website for Fosho, a hospital-specialist online marketing agency.

This repository contains only website runtime files. The approved V3 is now the main homepage. A comparison copy remains at `v3/` with indexing disabled. Project plans, research notes, source PDFs, and design reviews are excluded.

GitHub Pages publishes the `main` branch from the repository root.

- Homepage: https://huynjuunn-glitch.github.io/fosho-homepage-site/
- Comparison: https://huynjuunn-glitch.github.io/fosho-homepage-site/v3/

Canonical URLs, social metadata, structured data, and sitemap URLs are generated together. Update their source base URL before connecting a custom domain. `robots.txt` is only read as the site's policy when served at the hostname root.
