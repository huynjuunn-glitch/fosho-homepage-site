# Fosho homepage

Public static website for Fosho, a hospital-specialist online marketing agency.

This repository contains only website runtime files. V2 remains at the repository root; the approved V3 preview is available at `v3/`. Project plans, research notes, source PDFs, and design reviews are excluded.

GitHub Pages publishes the `main` branch from the repository root.
